# RETEX EMPIRE — Arizona RP Tucson

Промо-сайт семьи RETEX EMPIRE для сервера Tucson.

## Публикация через GitHub Pages
1. Откройте Settings → Pages в репозитории.
2. В разделе Build and deployment выберите Deploy from a branch.
3. Выберите ветку `main` и папку `/(root)`, затем Save.
4. После публикации сайт будет доступен по адресу: https://maginster.github.io/Retex.Empire.github.io/

## Настройка контента
- Тексты, блоки и ссылки находятся в `index.html`.
- Замените текстовые описания и заполните настоящие игровые ники руководства.
- В блоке «Вступить» добавьте ссылку на Discord/контакт семьи, когда она будет готова.

Сайт статический: не требует сервера, сборки или базы данных.
